====================================================
ゲームタイトル：Lumina Path
====================================================

【コンパイル方法】
Makefileを作成したため、本ディレクトリ内で以下を実行して、コンパイルする。
    make
実行方法
    Windows: ./game.exe
    Linux/macOS: ./game


【ゲームのプレー方法】
レーザーを操作し、ミラーやプリズムを適切に配置することで、ターゲットに指定された色の光を当てるパズルゲーム
◇基本操作
    ・マウス操作のみでプレイ可能
    ・レーザー発射台の黄色ノードをドラッグすることで、レーザー発射方向の回転可能
    ・画面下部のインベントリからミラー/プリズムをドラッグして配置
    ・ミラー/プリズムは片方のノードをドラッグして移動、もう片方のノードをドラッグして回転
    ※デバッグ・確認用として、キーボードの1~0キーを押すと対応するステージに直接移動可能
    （※通常プレイでは使用しない想定）

◇ルール
    ・全10ステージ
    ・ターゲットにレーザーを当てると、色のエネルギーが蓄積
    ・ターゲットが要求する色を満たすとステージクリア
    ・ミラー：光の進行方向のみを変化（反射）
    ・プリズム：白色講をRGBに分光
    ・分光された光を組み合わせることで捕色・混色を作成可能
    ・間違った色をターゲットに当ててしまうと汚染ゲージが増加
    ・汚染ゲージがいっぱいになったらステージオーバー → [R]でステージをリトライ


【工夫した点】
・ベクトル関数を自作関数として実装
・色混合ロジックはビットフラグで管理
・レーザー処理は再帰関数で実装し、制限を設けることで関数内の無限ループも防止した
・レーザーの進行を少しずつ進める方式にして、重力や空間のゆがみなどの特殊な効果を表現
・処理を段階的に分岐し、さまざまなモードを実装
・Makefileを使用し、コンパイルを簡潔に
・ヘッダ・ソースファイルを役割ごとに分割
　・common.h：ベクトル演算、数学関数（インライン）
　・game_logic.h/game_logic.c：ゲーム定数、ロジック
　→機能追加を想定し、拡張しやすい構成
・実際に何度も試しながら、ぎりぎりステージクリアできるようなターゲットやレーザー、壁の位置、ミラー/プリズムの数などを設定

【アピールポイント】
・ステージ8以降では宇宙や深海をテーマにしたギミックを導入
・重力によるレーザーの湾曲や、ブラックホールの描画、視覚的に分かりやすいレーザーの発光表現などの視覚表現
・ミラー/プリズム接触時の効果音や、ステージ全体のBGM演出による聴覚表現
・ステージが進行するごとに適度に難しくなっていき、学習しながらプレイが可能
・汚染ゲージにより、プレー中の試行錯誤の過程に緊張感を持たせる

【今後の改善点】
・さらにステージを追加したかった。
　案としては、宇宙ステージで赤方偏移を用いた色変化ギミックや、屈折率の異なる媒質を考えていたが、実装の難易度が高く断念
・ミラー/プリズムの操作感をもっと直感的にしたかった。
